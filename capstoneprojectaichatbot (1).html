01 — The Problem

A campus with too many front doors

Like a lot of schools, ours didn't run one website — it ran several: one for admissions, one for academics, one for student life, plus a few standalone pages and PDFs nobody remembered to link together. Each had its own layout, its own menu, its own idea of where things belonged.

Students felt it first, especially those still building their English. Three questions came up over and over, and the "right" page was never where anyone expected it to be.

?How do I apply for this?
?Where's the bus schedule?
?How do I pay tuition?
02 — The Fix

One chatbot, every site's answer

Instead of redesigning every site — a project with no budget and no timeline — I looked for a way to put one front desk in front of all of them. I found Noupe, a free no-code AI chatbot builder, and it fit the constraints exactly: no developer, no IT ticket, and it could read what already existed on the website rather than needing everything re-entered by hand.

03 — How It Was Built

From idea to embedded widget

No development environment, no code editor — the whole build happened inside Noupe's dashboard.

1

Listen first

Asked around for what students actually got stuck on. The same three kept surfacing: bus schedule, tuition payment, applications.

2

Point it at the website

Gave Noupe the school's URL. It crawled the public pages and started building its own answer base — no manual data entry.

3

Fill the gaps

Bus timetables and payment steps didn't live in tidy web copy, so they went into the knowledge base as documents and Q&A pairs.

4

Turn on multiple languages

Enabled automatic language detection so the bot answers in whatever language the visitor is typing — no separate setup per language.

5

Make it feel like the school's

Set the greeting message, avatar, and color so it read as part of the site instead of a bolted-on plugin.

6

Embed it

Pasted the widget's embed code into the site template. Live the same day.

7

Watch and refine

Used real conversation transcripts to spot missing answers and keep the knowledge base current.

05 — Reflection

What this project taught me

A no-code tool put a real fix within reach without needing a developer or a budget line — the gap between noticing a problem and shipping something for it got a lot shorter.

Automatic language detection solved, in an afternoon, a barrier that a formal translation project could have taken a year to get around to.

The chatbot is only as good as the content behind it — it's a starting point for helping students find their way, not a replacement for fixing the confusing site structure underneath.

How to build a chatbot like this, no coding needed

  • Start with Noupe (free, no credit card) and give it your website's URL — it reads the public pages on its own.
  • Add anything the site doesn't cover well as a document or Q&A pair in the knowledge base.
  • Turn on multi-language support if any of your visitors aren't native speakers of the site's main language.
  • Set the greeting, avatar, and color, then copy the embed snippet into your site.
  • Check the conversation inbox weekly and keep feeding it the questions people actually ask.
